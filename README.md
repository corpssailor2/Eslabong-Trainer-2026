## 🎮 About the Game

Eslabong is a medieval arena combat and mercenary club management game developed and published by shirowita. It entered Early Access on August 24, 2026, for Windows PC. The game combines action, strategy, simulation, tactical combat, and management gameplay.

## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Eslabong**. This trainer supports Eslabong’s arena battles and club-management systems with controls for gold, roster progression, combat survivability, abilities, and seasonal resources.

**Target Audience:** Players who want to experiment with team builds, test mercenary classes and abilities, reduce repetitive management, or enjoy easier solo and local cooperative arena sessions.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## 📖 Detailed Feature Guide

### Movement & Exploration

During direct-control matches, move the selected fighter around the arena and use positioning to avoid attacks, create distance, approach targets, and set up aimable abilities. Activate movement-related trainer options before entering combat when you want safer positioning.

### Tools & Inventory

Recruit mercenaries from the dynamic market, equip the roster, and manage relics between matches. Enable resource or inventory options only after the relevant club, roster, or relic screen has loaded, then make the desired changes and save normally.

### World & Environment

Eslabong progresses through seasons, leagues, cups, tournaments, and additional challenges. Gold and progression options are most useful between matches for expanding the club, improving fighters, preparing lineups, and testing different roster combinations.

### Combat & Weapons

Choose between controlling a captain directly in real time or relying on autobattle tactics. Activate health, mana, or cooldown options after the arena has loaded. Use the trainer for solo or local sessions and disable all combat options before entering asynchronous multiplayer content.
